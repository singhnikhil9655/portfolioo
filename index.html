Web3 / Blockchain

CropTrust

A blockchain-based agricultural platform designed to connect farmers and buyers through smart contracts and QR-code supply-chain traceability.

  • Polygon
  • Smart contracts
  • React
  • QR codes

Problem

Buyers rarely see where produce came from, and farmers have limited direct access to buyers.

Goals

  • Supply-chain transparency
  • QR-based product tracking
  • Smart-contract integration
  • Farmer-to-buyer connectivity

Workflow

Farmer lists a batch, a smart contract on Polygon records it, a QR code on the product links to that record, and the buyer scans to verify the farm-to-market trail.

Technologies

Polygon smart contracts, React, QR-code generation.

Machine Learning / Computer Vision

EVAI Guardian

A dual-purpose software concept for electric vehicle battery-health monitoring and driver drowsiness detection using machine learning and computer vision.

  • Computer vision
  • Machine learning
  • Digital twin
  • Python

Problem

Driver fatigue and battery degradation are both safety risks in electric vehicles, and they are usually monitored separately.

Goals

  • Battery-health visualization
  • Driver monitoring
  • Computer-vision workflow
  • Data-driven safety insights

Workflow

A camera feed is analyzed for signs of driver fatigue while battery data feeds a digital-twin view of battery health. Both streams produce one safety summary.

Technologies

Python, computer vision, machine learning.

Status

A software concept. It is not a deployed in-vehicle system.

AI / Deep Learning

Credit Card Fraud Detection

A machine-learning project exploring suspicious transaction detection using a hybrid approach involving deep neural networks.

  • Autoencoder
  • Attention
  • Python
  • Explainable AI

Problem

Fraud is rare compared with legitimate transactions, so models must handle heavy class imbalance and explain their decisions.

Goals

  • Transaction classification
  • Data preprocessing
  • Class-imbalance handling
  • Precision, recall and model evaluation

Workflow

Preprocess transactions, train a hybrid attention-autoencoder model, then evaluate with precision and recall rather than accuracy alone.

Technologies

Python, deep neural networks, autoencoders, attention.
